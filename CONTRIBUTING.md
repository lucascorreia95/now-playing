# Contribuindo para YouTube Music Now Playing

Contribuições são bem-vindas! Este é um projeto open source e agradeço qualquer ajuda.

## Como Contribuir

### Reportando Bugs

Se você encontrou um bug, por favor:

1. Verifique se já existe uma issue reportando o mesmo problema
2. Se não existir, crie uma nova issue com:
   - Título descritivo
   - Descrição detalhada do problema
   - Passos para reproduzir
   - Comportamento esperado
   - Seu ambiente (Chrome versão, SO, etc.)
   - Screenshots se aplicável

### Sugerindo Funcionalidades

Se você tem uma ideia para melhorar o projeto:

1. Verifique se já existe uma issue para a funcionalidade
2. Se não existir, crie uma nova issue descrevendo:
   - A funcionalidade proposta
   - Por que ela seria útil
   - Como você imagina que ela funcionaria

### Enviando Pull Requests

Para contribuir com código:

1. Fork o repositório
2. Crie uma branch para sua feature (`git checkout -b feature/MinhaFuncionalidade`)
3. Commit suas mudanças (`git commit -m 'Adiciona MinhaFuncionalidade'`)
4. Push para a branch (`git push origin feature/MinhaFuncionalidade`)
5. Abra um Pull Request

### Código de Conduta

- Seja respeitoso com todos os colaboradores
- Use linguagem apropriada e profissional
- Aceite feedback construtivo
- Foque no que é melhor para o projeto

### Estilo de Código

- Siga o estilo de código existente
- Use comentários para explicar lógica complexa
- Escreva código limpo e legível
- Teste suas mudanças antes de enviar PR

Se você tiver dúvidas sobre como contribuir, sinta-se à vontade para abrir uma issue e perguntar!
